# 第 29 章 · ml:统一 StatModel 之下的 SVM/树家族与"OOB 默认不算"

> 基线:commit `d3d247f1`(4.13.0-dev)。核心:modules/ml/src/(svm.cpp 2,359 / tree.cpp 1,990 / ann_mlp.cpp 1,533 / data.cpp 1,045)。纠偏:**RTrees 的 OOB 误差默认根本不算**——仅当 TermCriteria 带 EPS 或 calcVarInterest=true 时才计算,否则 getOOBError() 恒返回 0(rtrees.cpp:163);决策树的 pruneCV(1-SE 剪枝)实现完整但调用点被注释,CVFolds 统计是无人消费的死路径(tree.cpp:265)。

## 29.1 SVM:五式归一的 SMO 与 Q 行缓存

solve_generic 把 C_SVC/NU_SVC/ONE_CLASS/EPS_SVR/NU_SVR 五种形式统一进一个循环,差异下沉为 GetRow/SelectWorkingSet/CalcRho 三个策略函数指针(svm.cpp:454-456);二变量解析消元按异号/同号约束分母取方向(:712-745),收敛判据 Gmax1+Gmax2<eps。Q 矩阵不物化,按行 LRU 缓存(40-500MB,"约 25% 的 Q 被用到"估行数),双链表 O(1) 淘汰(:524-584)。多类是 one-vs-one 训练 n(n-1)/2 个二分类;**LINEAR 训练后做 SV 折叠压缩**——Σα·sv 折叠成一个向量,原始 SV 在 getUncompressedSupportVectors(:1558-1608)。不可行 nu(某两类 nu·(ci+cj)/2>min)直接报错(:1456-1467);trainAuto 的交叉验证是"环形移位取折"(:1656-1720)。

## 29.2 树家族:Gini 代理、OOB 与 Boost

有序分裂质量 `quality=(lsum2·R+rsum2·L)/(L·R)` 代数上恒等于"左右类权重平方和占比"——Gini 最小化的等价代理(tree.cpp:675-706);类目多值超 maxCategories 先加权 k-means 聚类再枚举子集(:720-868)。RTrees 默认 maxDepth=5、每树随机取 √nvars 个变量;OOB 误差只在 EPS 或变量重要性时算,回归用运行均值、分类用跨树投票(rtrees.cpp:163-243);变量重要性是置换法+L1 归一(:247-296)。Boost 非 DISCRETE 强制转回归 ±1,叶值 DISCRETE 恒 ±1、REAL 为 0.5·log(p/(1-p)),weightTrimRate 裁小权重样本(boost.cpp:95-331)。useSurrogates(代理分裂)**未实现**,开了直接 CV_Error(tree.cpp:405-407)。

## 29.3 ANN_MLP 与 TrainData 细节

默认 SIGMOID_SYM+RPROP(0.1);激活 5 种含 RELU/LEAKYRELU;weights[0] 与尾行是输入/输出的 [scale,shift] 仿射(ann_mlp.cpp:470-573)。TrainData:getResponseType 判据是"类目标签是否为空"而非 varType(data.cpp:161-164);类目归一排序+哈希复用映射省内存(:359-381);calcError 未切分时自动回退全样本(inner_functions.cpp:147-152)。

## 29.4 设计动机

1. **StatModel 四语义**:isTrained/isClassifier/predict+train,属性系统复用 Algorithm 的 FileStorage(ml.hpp:318);
2. **SMO 策略注入**:五种 SVM 形式共享一个循环,差异最小化为三函数指针(svm.cpp:454-456);
3. **SV 压缩**:线性核预测只做一个点积,压缩版即接口(svm.cpp:1558-1608);
4. **Gini 等价代理**:分裂质量公式代数化简,注释给出推导(tree.cpp:675-706);
5. **OOB 惰性**:不算白不算的统计挂条件,默认路径零开销(rtrees.cpp:163);
6. **FLT_MAX=missing**:单哨兵贯穿 CSV/替代值/树预测三处(ml.hpp:148)。

## 29.5 FAQ

**Q1:训练完能直接取 OOB 吗?**
默认不能,getOOBError() 恒 0;需 EPS 或 calcVarImportance(rtrees.cpp:163)。

**Q2:missing 值怎么传?**
只有 loadFromCSV 的 FLT_MAX 路径;create 的 missing 形参硬编码 noArray()(data.cpp:1039)。

**Q3:KNN 用 flann 吗?**
不用,暴力 L2+位模式 top-k;KDTREE 用模块自带 kdtree.cpp(knearest.cpp:173-416)。

**Q4:线性 SVM 的 SV 去哪了?**
被折叠压缩,getUncompressedSupportVectors 取原始(svm.cpp:1558-1608)。

**Q5:代理分裂能用吗?**
不能,未实现,开 useSurrogates 直接报错(tree.cpp:405-407)。

**Q6:Boost 能多分类吗?**
仅 DISCRETE;其余强制转 ±1 回归(boost.cpp:95-108)。

**Q7:RPROP 反号分支正确吗?**
按缩小步长前进,与教科书矛盾,疑似遗留 bug(ann_mlp.cpp:1246-1265)。

**Q8:trainAuto 的 CV 怎么实现?**
环形移位取折+参数网格并行(svm.cpp:1656-1720)。

**Q9:GBTrees 可用吗?**
新 API 已注释停用,只剩 CvGBTrees 遗留(ml.hpp:1388)。

**Q10:决策树剪枝在跑吗?**
pruneCV 实现完整但调用点被注释,CVFolds 统计白算(tree.cpp:265)。
