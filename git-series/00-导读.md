# 《Git 卷》导读:如何使用本卷

> 本卷是《源码深读 · 系统开源项目解读系列》**第三系列**。全部结论来自对 Git 源码(commit `47ce805`,2.52.0-rc1 附近)的逐行阅读,每处关键论断标注 `文件:行号`。

## 定位:与网上 git 内容的区别

不是"没人写过 git 解析",而是现有内容**旧、碎、不读源码**:

- 命令教程与"画 .git 目录树"式科普不在此列的对比范围;
- 最深的主流资料(Pro Git 第 10 章 Git Internals)停留在概念+手工演示,2021 年后未大更新,从不进 C 源码;
- Git 近五年的架构大变——**merge-ort 新引擎(2.34 默认)、reftable 引用后端、protocol v2、midx/cruft pack、sparse index、partial clone**——中文深读几乎为零;旧教程还在讲 packed-refs 是终态、merge 用 recursive 引擎(本 commit 中 merge-recursive.c 已被整体删除)。

本卷全部论断行号级验证、钉死 commit、覆盖上述新架构,并延续系列传统:每章"设计动机+FAQ+跨系列对照"(对象库 vs SQLite、repack vs LevelDB compaction、引用事务 vs etcd)。

## 这卷写给谁

与全系列一致:3-5 年后端经验、不需要版本控制理论背景的工程师。git 你天天在用——本卷回答的是"为什么 status 有时自己变慢""为什么 rebase 后 hash 全变""gc 什么时候真删对象"这类**每天发生但没人答过的问题**,答案带行号。

1. **系统通读**:卷一 01→07(对象→引用→索引→存储→传输→合并→文化),卷二 08→11(性能/fsck/多仓库/架构);
