# 第 14 章 · 表达式执行与标量函数机器:8 类分发与 sel 透传

> 基线:commit `7e886f44`。核心:src/execution/expression_executor.cpp / scalar_executor.hpp / function_binder.cpp / function/scalar/。

## 14.0 全景:`a*b+1 > 10` 的执行树

```
 绑定期:ColumnBindingResolver 已把列引用换成物理下标(column_binding_resolver.cpp:224-248)
 BoundFunctionExpression ">"(ANY/ANY + Select 回调)
 ├── BoundFunctionExpression "+"(int64 重载,profile={flat,const} → ExecuteFlat<CONSTANT_MASK=2>)
 │   ├── BoundFunctionExpression "*"(溢出检查重载)
 │   │   ├── BoundReferenceExpression a(零拷贝 Reference)
 │   │   └── BoundReferenceExpression b
 │   └── BoundConstantExpression 1(常量向量广播)
 └── BoundConstantExpression 10
 Select 路径:BinaryExecutor::Select → true_sel=[3,17,42,…](行号,非布尔向量)
 逐级收窄的只有行号集合;Execute(非过滤)路径每层物化完整 FLAT 结果
```

纠偏:执行器的 switch **只剩 8 个绑定类**(REF/CASE/CONJUNCTION/CONSTANT/FUNCTION/LAMBDA/OPERATOR/PARAMETER,expression_executor.cpp:279-306)——比较是 ANY/ANY+Select 回调的标量函数(comparison.cpp:82-97),CAST 在绑定期被物化为 `__cast` 标量函数(cast.cpp:186-200),没有 BOUND_COMPARISON/BOUND_CAST 分支。

## 14.1 三种粒度入口与 DefaultSelect

多列 Execute 逐列执行后统一 Verify(:85-95);`SelectExpression` 支持 true_sel/false_sel **双向输出**(:120-129)。Select 的 switch 只给 CONJUNCTION 与 FUNCTION 定制路径,其余走 DefaultSelect:栈上物化 `bool intermediate_bools[2048]` 再扫一遍生成 sel,validity 无 NULL 时走 NO_NULL 模板消掉判空(:315-356)。STANDARD_VECTOR_SIZE=2048(vector_size.hpp:16-21)。叶子类零成本:REF 收到 sel 就 Slice、没有就零拷贝 Reference(execute_reference.cpp:13-23);CONSTANT Reference 常量向量。DEBUG 构建下复用的 FLAT 结果向量必须全 valid,防上一 chunk 脏掩码泄漏(:258-269)。

## 14.2 AND/OR:短路不在 boolean_operators

纠偏:`VectorOperations::And/Or` 是**全量物化**三值逻辑、不传播 selection vector(boolean_operators.cpp:16-62);短路+行集逐级收缩+AdaptiveFilter 运行时重排子谓词顺序,全在 conjunction 的 Select 路径(execute_conjunction.cpp:66-145)。另有两层字典优化:UnaryExecutor 在字典大小×2≤count 时只对字典执行(unary_executor.hpp:123-140);函数态还有 20000 大小上限/50% 填充率的可复用输出字典缓存(execute_function.cpp:49-132)。

## 14.3 标量函数 SDK:单轨化

纠偏:不存在 RegularFunction vs VectorizedFunction 双轨——唯一执行形态是 `scalar_function_t(DataChunk&, ExpressionState&, Vector&)`(scalar_function.hpp:133);select/statistics/to_string/filter_prune/bind_lambda/init_local_state 等全是可选叠加回调(:174-207)。DECIMAL 重载的 function 指针为 nullptr,实现延迟到 bind 按精度决定(arithmetic.cpp:1091 起);`SetFallible/SetVolatile` 高频;CANNOT_ERROR 的函数若真抛错会被改写为 InternalException(scalar_function.hpp:209-212)。overload 一经绑定不可变,function_set_base.hpp:28-38。

## 14.4 重载解析:cast 代价求和 + TEMPLATE 推导

第一步按"逐参隐式 cast 代价求和"选 overload:代价表 TargetTypeCost 是偏序表——BIGINT=101 < INTEGER=102 < DOUBLE=104 < DECIMAL=105 < VARCHAR=149 < TEMPLATE=1000000;**整数字面量装进目标整型时给 cost−90 优惠**(这就是 `2.5+3` 免显式 cast、整数偏好 BIGINT 的原因),平票抛 "Could not choose a best candidate"(cast_rules.cpp:9-52, 414-430; function_binder.cpp:238-334)。第二步逐 child 插入 BoundCastExpression。本 commit 引入 C++ 式 TEMPLATE 类型推导:`InferTemplateType` 深入 LIST/MAP/STRUCT 子类型,冲突时 TryGetMaxLogicalType 单化(function_binder.cpp:780-907);DEFAULT_NULL_HANDLING 的函数任一 child 可折叠为 NULL 时,整个函数在 bind 期直接折叠成 NULL 常量(:619-652)。

## 14.5 ScalarExecutor:按输入 profile 特化

热循环引擎先对全部输入做 InputProfile 采样(常量?平坦?字典?),按 profile 选 `ExecuteFlat<CONSTANT_MASK>` / ExecuteStandard / 扁平化路径(scalar_executor.hpp:31-40)——常量操作数以 CONSTANT_MASK 编译期特化免广播。函数节点执行前 `intermediate_chunk.Reset()`,孩子结果写进 arguments.data[i](execute_function.cpp:201-204)。优化器的常量折叠引擎 `EvaluateScalar` 就是"造 executor 跑 1 行"(expression_executor.cpp:142-155)。

## 14.6 设计动机

1. **8 类分发点**:比较/CAST 函数化后,新增表达式形态不再改执行器(expression_executor.cpp:279-306);
2. **sel 透传**:过滤路径只收缩行号集,向量不裁剪,内存零复制(:315-331);
3. **profile 特化**:常量/平坦输入编译期模板特化,热路径无分支(scalar_executor.hpp:31-40);
4. **cast 代价偏序表**:重载解析可解释、可扩展(整数字面量 −90 优惠)(cast_rules.cpp:414-430);
5. **bind 期折叠**:NULL 传播在绑定期完成,运行期少一层判断(function_binder.cpp:619-652);
6. **字典复用缓存**:小基数列的函数输出可整块复用(execute_function.cpp:49-132)。

## 14.7 FAQ

**Q1:比较运算是内置表达式类型吗?**
不是,是标量函数(ANY/ANY+Select 回调)(comparison.cpp:82-97)。

**Q2:CAST 呢?**
绑定期物化为 `__cast` 函数的 BoundFunctionExpression(cast.cpp:186-200)。

**Q3:AND 的短路在哪实现?**
conjunction 的 Select 路径,不在 VectorOperations::And(execute_conjunction.cpp:66-145)。

**Q4:Select 与 Execute 的区别?**
Select 只产出行号集合(支持双向),Execute 物化完整结果向量。

**Q5:重载怎么选?**
逐参隐式 cast 代价求和,平票报错(function_binder.cpp:238-334)。

**Q6:为什么 2.5+3 不用显式 cast?**
INTEGER_LITERAL 优惠 −90;代价表 BIGINT<INTEGER(cast_rules.cpp:414-430)。

**Q7:字典输入会整块执行吗?**
字典×2≤count 时只对字典执行(unary_executor.hpp:123-140)。

**Q8:函数能声明"永不报错"吗?**
CANNOT_ERROR;违者改写 InternalException(scalar_function.hpp:209-212)。

**Q9:NULL 参数会跳过函数执行吗?**
DEFAULT_NULL_HANDLING 下 bind 期整体折叠为 NULL 常量(function_binder.cpp:619-652)。

**Q10:常量折叠在哪跑?**
EvaluateScalar:造 executor 跑 1 行(expression_executor.cpp:142-155)。

## 14.8 小结与深挖方向
