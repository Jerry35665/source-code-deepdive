# 第 02 章 · 类型系统与向量化:数据基座

> 基线:commit `7e886f44`。

## 2.0 全景:一个 DataChunk 的内存布局

```
DataChunk(data_chunk.hpp:44) = vector<Vector> data + optional_idx count
 └ Vector(vector.hpp:238-240)仅 { LogicalType type; buffer_ptr<VectorBuffer> buffer }
    └ VectorBuffer(vector_buffer.hpp:215-218)内含:
       vector_type(FLAT/CONSTANT/DICTIONARY/SEQUENCE/FSST/SHREDDED)+ v_size(行数)
       + StandardVectorBuffer{ ValidityMask validity; data_ptr_t data_ptr }
       + auxiliary_data(字符串 heap / struct children / list child 挂载点)
string_t 16 字节(string_type.hpp:243-255):
       len≤12 → 内联 inlined[12];len>12 → length(4B)+prefix(4B)+ptr(8B)
```

**纠偏**:2026 主干的 Vector 不再直接持有 data/validity/count——全部下沉进 buffer,`Reference` 一个向量=交换一个 shared_ptr(vector.cpp:110-118),浅拷贝/切片/字典共享都成引用计数操作。

## 2.1 双层类型:LogicalType→PhysicalType

约 50 个 `LogicalTypeId`(types.hpp:193-258)经 `GetInternalType()` 单向映射到 ~15 种 PhysicalType(types.cpp:63-176)。三个要点:①时间族物理退化为定长整数——DATE→INT32,TIMESTAMP 六种粒度共享 INT64(types.cpp:75-91);②**DECIMAL 按宽度选物理型**:width≤4→INT16、≤9→INT32、≤18→INT64、≤38→INT128(types.cpp:103-120,阈值 decimal.hpp:41-45),width/scale 存 ExtraTypeInfo 剥离出热路径;③嵌套类型映射为容器:STRUCT 物理大小为 0 字节、LIST 为 8 字节 list_entry(types.cpp:359-364)。"类型 id→字节数"全表 `GetTypeIdSize`(types.cpp:326-368)是向量分配、行布局、buffer 管理三处共用的定宽基石。

## 2.2 四种向量形态与统一读接口

- **FLAT**:逐行数组;**CONSTANT**:1 个值冒充 n 行——`Reference(Value)` 构造单值 buffer 后 SetVectorSize(count)(constant_vector.cpp:32-35),广播 join 键零拷贝;
- **DICTIONARY**:SelectionVector + 子向量(DictionaryBuffer::entry->data,dictionary_vector.hpp:100);filter/slice 只动 4 字节行号数组;
- **SEQUENCE**:只存 {start, increment} 无数据数组(sequence_vector.hpp:15-20),用于 rowid 虚拟列。

读取端统一走 `ToUnifiedFormat`(vector.cpp:458-467,原名 Orrify 致敬 Orri Erling):flat/constant/dictionary **零成本**转成 `{data, validity, sel}` 规范格式,FSST/SEQUENCE/SHREDDED 才先 Flatten;下游统一写 `data[sel->get_index(i)]`,无需逐形态特判。

## 2.3 string_t:16 字节三件套

`INLINE_BYTES=12 / PREFIX_BYTES=4 / HEADER_SIZE=8`(string_type.hpp:28-31)。相等比较先用两个 uint64 批量比 length+prefix,不等即短路(string_type.hpp:173-195);大小比较用 prefix 做 bswap 后整数比较(:203-215)——**长串比较多数情况不必解引用 ptr**。写入方必须调 `Finalize()` 填 prefix,debug 下 `VerifyCharacters` 专查"prefix=真实前 4 字节"(string_type.cpp:40-50)。超长串入 `VectorStringBuffer` 的 StringHeap(string_heap.hpp:44:AddBlob 内联阈值判断)。

## 2.4 ValidityMask 与 SelectionVector

ValidityMask 按 64 位字位图组织(2048 行=32 字=256 字节,validity_mask.hpp:64-66);核心编码:**mask 指针为 nullptr 即"整列无 NULL"**——判定退化为一次指针判空返回常量(:82-87,153-158),首次 SetValid 才分配 256 字节。SelectionVector 的语义是"未设置则恒等":`get_index(idx) = sel_vector ? sel_vector[idx] : idx`(selection_vector.hpp:136-139)——谓词过滤只产出命中行号数组,数据一个字节不搬;切片在 dictionary 之上组合 sel 而非拷数据(dictionary_vector.cpp:145-160)。

## 2.5 DataChunk 与 cast 矩阵

chunk=列向量组+行数;新特性:**行数可从子向量推导**(DeriveSize,data_chunk.cpp:77-89),SetCardinality 已 deprecated。`STANDARD_VECTOR_SIZE=2048`(vector_size.hpp:16),静态断言必须为 2 的幂(:23-25)。执行循环靠 `VectorCache` 复用内存(vector.cpp:205-207)——每算子每次输出不重新 new 16KB 数组。cast 调度中心 `CastFunctionSet::GetCastFunction`(cast_function_set.cpp:54-86):同型→NopCast;扩展注册优先;内建 DefaultCasts 按 30 余个 `*CastSwitch` 分发,嵌套类型逐 child 递归取函数;`ImplicitCastCost` 代价表供 binder 裁决隐式转换(:187-219)。

## 2.6 设计动机

1. **2048 行 chunk**:2^12 行×8-16 字节≈16-32KB/列,与 L1/L2 同量级;2 的幂使位定位全走位运算;
2. **LogicalType/PhysicalType 分离**:执行器只写 ~15 种模板特化,新增时间粒度零新增算子;
3. **string 内联+前缀**:短键零堆分配,比较/hash/排序免解引用;
4. **惰性物化**:constant O(1) 内存表达 n 行,dictionary 让 filter 只动行号;代价推给读取端统一 sel 间接寻址;
5. **NULL 用空指针编码**:绝大多数列无 NULL,热循环零开销。

## 2.7 FAQ

**Q1:一个 chunk 几行?**
默认 2048(vector_size.hpp:16),编译期可覆盖,必须 2 的幂。

**Q2:VARCHAR 列每行占多少?**
16 字节 string_t(string_type.hpp:243);内容超 12 字节进 heap。

**Q3:dictionary 向量何时被物化?**
读取端大多零成本(ToUnifiedFormat);序列化时统计 used*2<count 才值得只存子集(vector.cpp:526-556)。

**Q4:NULL 怎么存?**
独立于数据的 ValidityMask 位图;无 NULL 时指针为 nullptr 零开销。

**Q5:DECIMAL(38,2) 物理上是什么?**
INT128(hugeint);width≤18 则 INT64(types.cpp:103-120)。

**Q6:struct/list 的子数据在哪?**
不在 Vector 内,挂 VectorStructBuffer::children / VectorListBuffer::child(struct_vector.hpp:69、list_vector.hpp:74)。

**Q7:两个 chunk 怎么零拷贝传递?**
Reference 交换 shared_ptr + 复制 count(vector.cpp:110-118)。

**Q8:cast 找不到函数会怎样?**
回落 `TryVectorNullCast`(cast_function_set.cpp:86)——目标全 NULL。

**Q9:SEQUENCE 向量什么时候被迫物化?**
ToUnifiedFormat 无法提供行寻址,唯一必须先 Flatten 的常规形态(vector.cpp:458-467)。

**Q10:排序/聚合怎么处理变长列?**
打散成定长行布局(TupleDataLayout),string 仍以 string_t 表示(tuple_data_layout.hpp:43-97)。

## 2.8 小结与深挖方向

本章结论:**数据基座="双层类型+多态 buffer+三件惰性物化(constant/dictionary/sel)+空指针 NULL 编码"**。深挖:

1. SHREDDED 向量(嵌套部分削解)的完整语义(vector_type.hpp:15-22);
2. DictionaryEntry 可复用全局字典的 id 机制(dictionary_vector.hpp:23-30);
3. VectorCache 递归 reset struct/list child 的实现(vector_cache.cpp:51-84);
4. AddHeapReference 防 heap 提前释放的引用图(vector.cpp:303-313);
5. FSST 字符串压缩向量与存储层压缩的分工。
